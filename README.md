# CICLO — app do personal trainer

## Como publicar (passo a passo sem usar comandos)

1. Crie uma conta gratuita em https://github.com (se ainda não tiver)
2. Crie um novo repositório (botão verde "New")
   - Nome: ciclo-app
   - Deixe como "Public" ou "Private", tanto faz
   - NÃO marque nenhuma caixinha de "add README" (já vem uma aqui)
3. Na tela do repositório vazio, clique em "uploading an existing file"
4. Arraste TODOS os arquivos e pastas desta pasta (menos o README.md, que pode subir também)
5. Clique em "Commit changes"
6. Crie conta em https://vercel.com — escolha "Continue with GitHub" (mais fácil)
7. No Vercel, clique em "Add New" > "Project"
8. Selecione o repositório "ciclo-app" que você acabou de criar
9. Deixe tudo como está (o Vercel detecta que é Vite sozinho) e clique em "Deploy"
10. Em 1-2 minutos seu app está no ar, com um link tipo ciclo-app.vercel.app

Pronto — esse link é o que você compartilha com os personais que comprarem.
